## Dress code — qué es y qué recomiendo

**Dress code = código de vestimenta**: la línea que le dice al invitado cómo vestirse para no quedar
fuera de lugar (ni de traje si es informal, ni de jean si es de gala).

Los tres habituales para unos 15:

| Opción | Qué significa | Cuándo conviene |
|---|---|---|
| **Formal / Gala** | Traje y vestido largo o cocktail, zapatos de vestir | Salón, cena, fiesta grande |
| **Elegante sport / Cocktail** | Camisa y pantalón de vestir, vestido corto. Sin corbata obligatoria | Lo más común y lo más seguro |
| **Temático** | Los invitados siguen una paleta o un motivo | Cuando la fiesta tiene tema fuerte (acá: galaxia) |

Para una fiesta con temática espacial, mi recomendación:

> **"Elegante sport en clave galaxia — paleta: negro, azul noche, plata y dorado. Evitá el blanco."**

Es claro, no obliga a nadie a comprar ropa, y le deja el blanco (o el color que ella elija) reservado a
Tiana. Si ella ya eligió un color de vestido, se agrega: *"evitá el [color], lo reserva la quinceañera"*.
